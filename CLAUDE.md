# Grosslytics

Read `HANDOFF.md` before anything else: it is the current state of the project (what exists, what is deployed, what is unverified), so old conversations don't need replaying.

At the end of every task, update `HANDOFF.md`: add or edit a dated section saying what changed, what was verified, and what is not done or not deployed. Keep it current, not a log: rewrite stale lines instead of appending contradictions.

Never read or print `.dev.vars` or `.secrets/`.
